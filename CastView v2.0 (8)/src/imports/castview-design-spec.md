Design a multi-screen B2B SaaS web application called CastView — an AI model visualization platform for modeling agencies.
Color palette:

Background: #080808 (near black)
Surface / card background: #111111
Elevated surface: #1a1a1a
Primary text: #f0f0ec (ivory white)
Secondary text: #a0a09a
Accent / border: #c8c8c2
Bright accent: #e8e8e2
Subtle border: #2a2a2a

Typography:

Display headings: Cormorant Garamond, light weight, large and editorial
Body and UI text: DM Mono (monospaced)
Labels and tags: Syne, uppercase, tight letter-spacing

Overall aesthetic: High-fashion editorial. Think Vogue meets developer tool. Minimal, dark, precise. No gradients, no rounded corners (max 4px radius), no color fills. Everything feels intentional and sparse.

Design these 5 screens in sequence, connected by a top progress bar showing: Dashboard → Profile → Rendering → Results → Share

Screen 1 — Dashboard
Left sidebar navigation with: CastView wordmark at top, nav items (Dashboard, Prospects, Renders, Shared, Settings), small avatar at bottom.
Main content: Page title "Prospect Pipeline". Four stat cards in a row showing: 24 Prospects, 11 Renders, 6 In Review, 3 Shortlisted — each card is dark surface with a large monospaced number and a small label beneath.
Below: a table/list of prospects. Each row shows: a small square placeholder for a photo, model name, status badge (New / Rendering / In Review / Shortlisted — each a different muted color), submission date, and a right arrow. Rows are separated by very subtle 1px borders.

Screen 2 — Prospect Profile
Breadcrumb at top: Dashboard > Sofia Andersen
Left column: 2x2 grid of digitals (square photo placeholders labeled Front, Profile, 3/4, Full Body). Below: measurements panel in monospaced text — Height, Bust, Waist, Hips, Shoe, Hair, Eyes, all left-aligned in a clean key/value list.
Right column: Name in large Cormorant Garamond. Market availability tags. Agent notes text area. Below: "Select Shoot Context" — a 3x3 grid of chips: Fragrance, Editorial, Runway, Campaign, Beauty, Sportswear, Swimwear, Couture, Street. Each chip is outlined, selectable, toggles to filled when active. Below that: render quality selector — Standard / High / Ultra as three toggle buttons. At the bottom: a full-width CTA button "Generate Renders" in ivory on dark.

Screen 3 — Rendering in Progress
Centered layout. Large name at top. A vertical step tracker down the center showing 5 steps: Analysing Digitals (complete with checkmark), Fragrance (active with animated pulse dot), Editorial (pending), Campaign (pending), Scoring (pending). Each step has a label and a subtle percentage or status. Below: estimated time remaining in monospaced type. Minimal and calm — this is a waiting state.

Screen 4 — Results
Page title: "Sofia Andersen — Render Results"
Main area: 2x2 grid of render cards. Each card has a large dark square (image placeholder), a shoot context label underneath (e.g. "Fragrance"), and a score percentage in large Cormorant Garamond (e.g. "94%"). One card is highlighted / selected with an ivory border.
Right panel (sidebar): "AI Fit Score" heading. Four score rows: Composition 91%, Style Match 96%, Versatility 88%, Market Fit 94% — each shown as a label, a thin horizontal progress bar, and a percentage. Below: team notes text field. Below: three action buttons — Shortlist, Share Package, Pass.

Screen 5 — Share Package
Page title: "Share — Sofia Andersen"
Left: checklist of renders to include — each item shows context name, score, and a checkbox. All checked by default.
Center: delivery method selector — three cards: Share Link, Export PDF, Send Email. Share Link is selected/active.
Right: a generated link field with copy button, expiry date selector dropdown, password toggle. Below: a "Send to Client" button. Clean and minimal.

Spacing and details:

24px base spacing unit
All cards have 1px #2a2a2a borders
Status badges are small, uppercase, monospaced, pill-shaped with very subtle background tints
No drop shadows — use border and background contrast only
The top progress flow bar should be a thin strip with step labels, the active step highlighted in ivory, completed steps dimmed
